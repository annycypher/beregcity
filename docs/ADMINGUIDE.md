## 10. Безопасность (Этап 1б) — что включено и что включить вам

**Уже включено (кодом, менять не нужно):**
- Вход: `wp-login.php` переименован в `/bc-office-3184/` (слаг в `wp-config.php`,
  константа `BC_LOGIN_SLUG`; сменить адрес — изменить константу).
- `wp-login.php` и `xmlrpc.php` для гостя — 403; REST-эндпоинт пользователей — 404;
  перечисление авторов `?author=N` — редирект на главную.
- Из `<head>` убраны версия WordPress, RSD, WLW, короткие ссылки.
- `DISALLOW_FILE_EDIT` — правка файлов тем/плагинов из админки запрещена.

**Включить вам (2FA, скан, бэкапы):**
1. **2FA администратора (Wordfence):** Wordfence → Login Security → включить
   Two-Factor Authentication, привязать приложение (Google Authenticator/Authy),
   сохранить резервные коды. Обязательно для роли administrator (D19).
2. **Wordfence → Scan:** включить скан по расписанию (например, ежедневно/еженедельно).
3. **Wordfence → Firewall/Login Security:** включить лимит попыток входа (rate limiting)
   и блокировку перебора.
4. **UpdraftPlus → Настройки:** расписание — **БД ежедневно**, **файлы еженедельно**;
   хранилище — Яндекс.Диск (при первом сохранении нужно авторизовать доступ).
   После первой копии — сделать **тест восстановления** (хотя бы БД).

Формы организаций защищены антиспамом (honeypot, токен формы, отсечка «быстрее
3 сек», rate-limit 5 заявок/час) и e-mail-верификацией — см. §11.

## 11. Антиспам и фрод-индикаторы (Этап 3а-фрод)

**Антиспам на публичных формах** — работает сам, настраивать ничего не нужно:
- honeypot-поле (скрытое) + токен формы + отсечка заполнения быстрее 3 секунд;
- rate-limit: не более 5 заявок в час с одного IP;
- боту форма отвечает «спасибо», но письмо не уходит и запись не создаётся
  (фильтры не раскрываются).

**Фрод-индикаторы в «БерегСити → Утверждение карточек»:**
колонка «Фрод» показывает плашки-подсказки по каждой карточке:
- красные — «БЕЗ ФОТО», «ТЕКСТ < 200», «ВНЕШНЯЯ ССЫЛКА», «IP-СОВПАДЕНИЕ»
  (IP регистрации уже был у отклонённой карточки) — строка подсвечивается;
- серый «FREE-EMAIL» (mail.ru / yandex.ru / gmail.com) — просто информация.

Это подсказки, а не приговор: решение об одобрении/отклонении всегда ваше,
автоматической блокировки нет.

## 15. Заявки на права (Этап 3б, D38)

Витринная карточка (создана при импорте каталога) сначала без владельца. Если
организация нашлась — на карточке есть кнопка «Это ваша организация? Заявить
права»: заполняется форма, затем e-mail подтверждается по ссылке из письма.

Как обработать заявку (админка → БерегСити → Заявки на права):
1. Заявка видна в очереди (счётчик — 5-я плитка на дашборде). Зелёная подсветка
   строки = заявка уже подтвердила e-mail (готова к звонку).
2. Звоните ТОЛЬКО на телефон ИЗ КАРТОЧКИ (публичный номер организации), не на
   телефон из заявки. Цель — убедиться, что заявитель представляет организацию.
3. Дозвонились и подтвердили — «Подтвердить звонком → Привязать»: система
   создаст/найдёт пользователя по e-mail, привяжет карточку, поставит тариф Free
   (если был пуст) и отправит заявителю письмо «Доступ открыт» + ссылку /kabinet/.
   Новому пользователю отдельным письмом уходит ссылка для установки пароля.
4. Не дозвонились — «Отклонить» с причиной (обязательна). Шаблон причины
   «не удалось подтвердить по телефону». Организации уходит письмо с причиной,
   IP заявки попадает в список для фрод-проверки.

Просроченные заявки (в статусе «новая» более 14 дней) помечаются серым «просрочена».
Вкладки «Витрина (без владельца)» и «Клейменные» показывают карточки по источнику.
У клейменной карточки на тарифе Free описание ограничено 300 знаками; сайт,
соцсети и ярлыки — на тарифе Стандарт.
## 16. Тарифная визуализация фото (Этап 3б, D39)

- Где видно: карточки в каталоге и «Похожие рядом» (сепия — только free),

- На free выводится одно фото (обложка), миниатюры скрыты; нет фото — заглушка.

## 17. Отзывы организаций (Этап 4.5, D40)

Отзыв оставляет житель на карточке организации (раздел «Отзывы» → «Написать
отзыв»): имя, оценка 1–5, текст. Форма защищена от спама и требует согласия на
обработку персональных данных.

Как модерировать (админка → БерегСити → Отзывы):
1. Новые отзывы приходят в очередь; счётчик — плитка «Отзывы на модерации» на
   дашборде.
2. «Одобрить» — отзыв появляется на карточке и идёт в средний рейтинг.
3. «Отклонить» — отзыв уходит в корзину и не публикуется.

Ответ организации: владелец на тарифе Стандарт+ может ответить на отзыв прямо на
карточке (кнопка «Ответить» под отзывом) — ответ виден блоком «Ответ организации».

## 18. Каталог (Этапы 3.1–3.6)

Каталог — публичный раздел живого сайта (`/katalog/`). Организации ведутся как
записи типа «Организации» (админка → Организации), категории — таксономия
«Категории» (12 канон-категорий), дополнительные возможности организации —
«Снипеты» (34 в 6 группах, канон — СПРАВОЧНИК §3).

Что делает владелец:
- добавляет и редактирует организации (поля: телефон, адрес, график, сайт,
  соцсети, тариф, «проверен»);
- модерирует новые карточки — «БерегСити → Утверждение карточек», заявки на
  права — «БерегСити → Заявки на права» (§15);
- следит за описанием: витринная карточка (без владельца) выводится без
  описания; клейменная Free — описание до 300 знаков; Стандарт/Премиум — больше
  (D38).

Сортировка на странице каталога (выпадающий список «Сортировка»):
- «Сначала премиум» — по тарифу (Премиум → Стандарт → Триал → Free);
- «По названию» — по алфавиту;
- «По рейтингу» — по среднему рейтингу отзывов (выше — раньше; без отзывов —
  в конце); данные берутся из одобренных отзывов (§17);
- «Новые» — по дате публикации.

Фильтры по снипетам: внутри одной группы — «И», между группами — «ИЛИ» (D34).
Страницы с активными фильтрами закрыты от индексации (noindex), чистые URL
категорий — канонические (D32).
