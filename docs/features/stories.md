## Что важно знать об этом документе

1. **Это единственный файл по сторис** — прошлый stories.md перезаписывается. Все решения разбросанных сообщений (механика, внешний вид, D21, админ-страница, комбинированный режим) теперь в одном месте с ссылками на конкретные референсы.

3. **Три пометки ФАКТ-ПРОВЕРКА** (цена слайда, лимиты тарифов, цена переиздания) — после заполнения СПРАВОЧНИКА уберите их из §12 и §4–5, чтобы не путать агента.
