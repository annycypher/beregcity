# Реклама и контакты — памятка для владельца

## 1. Реклама: где и как

Админка → левое меню **«Баннеры»** → **«Добавить баннер»** (или откройте существующий).
В блоке «Параметры баннера»:

| Поле | Что делать |
|---|---|
| **Зона** | Выберите позицию, где баннер должен стоять (см. таблицу ниже) |
| **Изображение (компьютер)** | Картинка баннера. Нажмите «Добавить изображение» → вкладка «Загрузить» → файл → «Использовать изображение» |
| **HTML/код (для рекламных сетей)** | Вставьте код рекламной сети. Работает, только если картинка **не** выбрана |
| **Ссылка (куда ведёт кнопка)** | `/katalog/` или полный адрес `https://…`. Клики считаются |
| **Показывать** | Галочка. **По умолчанию выключена** — пока не поставите, баннер нигде не покажется |
| **Показывать до** | Дата автоснятия (пусто — показывать всегда) |

### Позиции и размеры

| Позиция | Где на сайте | Рекомендуемый размер |
|---|---|---|
| Главный баннер (слайдер) | Большой слайдер на главной | десктоп 1920×740, мобильный 800×800 |
| **Под шапкой** | Сразу под меню на главной | 970×90 |
| **После главного баннера** | Под слайдером | 1200×200 |
| **Под блоками разделов** | После новостей и афиши | 970×120 |
| **В конце главной** | Перед подвалом | 1200×160 |
| **Сайдбар каталога** | Слева в каталоге организаций | 300×600 или 300×250 |
| **Низ карточки организации** | Внизу страницы организации | 970×120 |
| **Баннер карты** | Вместо карточки «Открыть карту» | десктоп 1200×300, мобильный 720×280 |

Правила: пустая или выключенная позиция **не выводит ничего** — ни рамок, ни заглушек.
На телефоне баннер сжимается по ширине пропорционально (не сплющивается).

## 2. Контакты

Админка → **«Настройки сайта»** → **«Контакты»»**:

- **Телефон** + чекбокс **«Показывать телефон»** — пока галочка снята, телефона нет нигде на сайте;
- **Email**, **Telegram (ссылка)**, **ВКонтакте (ссылка)**, **Адрес**;
- **Текст для рекламодателей** — короткая подпись под контактами (например, «Реклама и сотрудничество»).

Пустые поля не выводятся. Соцсети в подвале показываются только если заполнены ссылки ВК/Telegram.
