# ADMINGUIDE.md — «БерегСити»: как владельцу вести сайт без программиста

Единственный документ, по которому владелец управляет сайтом. Каждая фича
считается закрытой только если: (1) работает по референсу `design/*.html`,
(2) ведётся из админки без кода, (3) описана здесь (принцип ТРИО, D18).

Обновляется по мере закрытия этапов. Последнее обновление: 02.10.2026 (Этап 1).

- Файлы WordPress: `C:\Users\krs3d\Local Sites\beregcity\app\public\`.
- Документы проекта: `C:\Users\krs3d\Local Sites\beregcity\` (`ПРОТОКОЛ.md`, `PROGRESS.md`, `DECISIONS.md`, `.clinerules`, папки `docs/` и `design/`).
- Продакшн (позже): beregcity.ru + зеркало берегсити.рф. Пока не куплено.

## 2. Запуск и остановка сайта

1. Откройте приложение **Local** (Local by Flywheel).
2. Выберите сайт **beregcity** в списке.
3. Нажмите **Start site** (верхний правый угол). Дождитесь статуса Running.
4. Чтобы выключить — **Stop site**. Сайт не работает, пока Local закрыт/остановлен.

## 3. Вход в админку

- Адрес: **http://beregcity.local/wp-admin/**
- Логин администратора: **owner**
- E-mail: `hello@beregcity.ru`
- Пароль задавался при создании сайта в Local. Если забыли: в Local слева у сайта
  есть кнопка смены пароля администратора (**WP Admin → пароль** или «Site shell»).

## 4. Вход в «оболочку» сайта (для WP-CLI, продвинутое)

В Local у сайта есть **Open site shell** — открывает терминал, где уже настроены
PHP, MySQL и WP-CLI. После этого доступны команды вида:

```
wp plugin list
wp option get blogname
wp post list
```

(Обычный PowerShell так не работает — нужны пути Local; поэтому используйте
встроенную оболочку Local.)

## 6. Если что-то сломалось

1. Откройте `app/public/wp-content/debug.log` — там текст ошибки.
2. Если сайт не открывается: в Local нажмите **Stop site → Start site**.
3. Не удаляйте и не правьте файлы ядра WP и папку `wp-content/themes/astra`
   (правки — только в `astra-child`).

## 7. Правила ведения контента

- Контент добавляется **только через админку** (не через код/SQL).
- Черновики, созданные с ИИ, остаются в статусе **draft** — публикуете вы после вычитки.
- Цифры, цены, телефоны берутся **только** из `docs/SPRAVOCHNIK-FAKTOV.md`.
  Сейчас справочник — скелет v0.9 и **не вычитан владельцем**; заполните его
  (в файле помечено `[ФАКТ-ПРОВЕРКА]` — таких мест 24).

## 8. Дизайн

- Источник правды по дизайну главной — файл `design/homepage.html` (DECISIONS D20).
  Классы и структуру HTML там не меняем; письменные описания палитры в протоколе —
  справочные.

## 9. Ритуал работы с ИИ

- Слова: «ПРОДОЛЖАЙ» — продолжить с первого шага без ✅ в `PROGRESS.md`;
  «СТАТУС» — показать `PROGRESS.md`; «ПЛАН» — план текущей фазы;
  «ПЕРЕДЕЛАЙ: …» — правки; «ОТКРЫВАЕМ» — публикация (только владелец).
- После каждого шага ИИ обновляет `PROGRESS.md` и делает коммит в git.
