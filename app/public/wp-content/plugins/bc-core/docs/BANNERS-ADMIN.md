# Баннеры на главной — памятка для владельца

Коротко: баннеры живут в админке, в разделе **«Баннеры»**. Каждый баннер = один слайд
в большой карусели на главной странице. Ничего в коде менять не нужно.

---

## 1. Где лежат баннеры

1. Зайдите в админку: `https://beregcity.ru/bc-office-3184/`
2. В левом тёмном меню найдите пункт **«Баннеры»** (иконка с картинками, обычно
   ниже «Записей» и «Медиафайлов»).
3. Откроется список: название баннера, дата. Нажмите на название → откроется редактор.

---

## 2. Как заменить картинку

1. В редакторе баннера найдите поле **«Изображение (компьютер)»**.
2. Нажмите на превью картинки → **«Заменить изображение»**
   (если поле пустое — кнопка **«Добавить изображение»**).
3. Откроется библиотека файлов → вкладка **«Загрузить»** → **«Выбрать файлы»**.
4. Выберите картинку на компьютере → «Открыть» → дождитесь загрузки.
5. Справа внизу нажмите **«Использовать изображение»**.
6. Внизу страницы — **«Обновить»** (синяя кнопка).

То же самое для поля **«Изображение для мобильных»** — там картинка для телефона.

---

## 3. Какое поле за что отвечает

| Поле | Что делает |
|---|---|
| **Зона** | Где показывать. Для главной выбирайте **«Слайдер главной (hero)»** |
| **Изображение (компьютер)** | Большая картинка для компьютера и планшета |
| **Изображение для мобильных** | Картинка для телефона (если пусто — покажется компьютерная, обрезанная) |
| **Видео (компьютер)** | Фон-ролик вместо картинки на компьютере: 1280×640, 6–8 с, без звука, до 2 МБ |
| **Видео (мобильные)** | Вертикальный ролик для телефона: 720×900, до 1 МБ |
| **Заголовок (крупно)** | Первая крупная строка, до ~50 символов |
| **Текст** | 2–3 короткие строки для компьютера |
| **Короткий текст для мобильных** | 1–2 фразы для телефона (если пусто — покажется обычный текст) |
| **Текст кнопки** | Надпись на кнопке, например «Смотреть каталог» (пусто → «Подробнее») |
| **Ссылка (куда ведёт кнопка)** | Адрес, куда попадёт человек после нажатия |
| **Показывать до** | Дата, после которой баннер исчезнет сам (пусто — показывать всегда) |
| **Рекламный / erid** | Только для платной рекламы (маркировка) |
| **Название сверху** («Добавить заголовок») | Служебное, видно только в админке |

---

## 4. Кнопка и ссылка

- **Своя страница сайта:** в поле «Ссылка» напишите `/katalog/`
  (обязательно со слэшем в начале).
- **Внешний сайт:** полный адрес, например `https://пример.рф/akciya`.
- **Пустая ссылка** → кнопка ведёт на главную страницу.
- Каждый клик по кнопке автоматически считается в статистике баннера.

Пример: «Текст кнопки» = `Смотреть каталог`, «Ссылка» = `/katalog/`.

---

## 5. Добавить / скрыть / удалить слайд

**Добавить:** «Баннеры» → **«Добавить баннер»** → заполнить поля → «Зона» = «Слайдер
главной (hero)» → **«Опубликовать»**. Новый слайд появится в конце карусели.

**Поменять порядок слайдов:** в редакторе баннера откройте блок **«Атрибуты»**
(справа или под редактором) и уменьшите **«Порядок»** — меньший номер показывается раньше.

**Скрыть на время:** переключите баннер в **«Черновик»** (кнопка рядом с «Обновить»)
или поставьте «Показывать до» прошедшей датой.

**Удалить:** в списке баннеров нажмите «В корзину». Восстановить можно из корзины
в течение 30 дней.

Если удалить/скрыть все hero-баннеры, на главной снова появятся стандартные
слайды-заглушки — сайт не сломается.

## 6. Требования к картинкам

- **Для компьютера: 1920 × 740 пикселей** (пропорция примерно 2.6 : 1 — широкая полоса).
  Минимум 1400 × 540. Больше не нужно.
- **Для телефона: 800 × 800 пикселей** (квадрат). На телефоне слайд почти квадратный,
  лишнее аккуратно обрежется по краям.
- **Формат:** WebP (лучше всего) или JPG. Без прозрачности, обычные цвета (sRGB).
- **Вес:** до 200 КБ на файл (проверить можно в проводнике: правый клик → «Свойства»).
- Если у баннера есть видео, постер лучше делать **1280 × 640** (компьютер) и **720 × 900**
  (телефон) — тогда он совпадает с первым кадром ролика и переход незаметен.

**Где оставлять «чистую зону» под текст:**

- на компьютере текст стоит **слева** → держите **правую треть** картинки свободной
  от лиц, логотипов и важных деталей;
- на телефоне текст идёт **поверх нижней части** → важное (лица, логотип, товар)
  размещайте в **верхней половине**;
- **не вписывайте текст в картинку** — весь текст задаётся полями выше: он останется
  чётким на любом экране, и его легко поменять без перерисовки картинки.
- лёгкое затемнение под текстом на телефоне появляется автоматически.

## 7. Видео вместо картинки (главный баннер)

Да, фон главного баннера может быть видео. Плашка с заголовком, текстом и кнопкой
остаётся сверху — её менять не нужно.

**Что загрузить**

| Файл | Размер | Вес | Куда |
|---|---|---|---|
| Видео для компьютера | 1280 × 640 (2:1), MP4, 6–8 с, без звука | до 2 МБ | поле «Видео (компьютер)» |
| Видео для телефона | 720 × 900 (4:5), 6–8 с, без звука | до 1 МБ | поле «Видео (мобильные)» |
| Постер (картинка до старта) | 1280 × 640 (ПК) / 720 × 900 (моб.) | до 200 / 120 КБ | поля «Изображение…» — обязательны |

- Постер обязателен: он показывается, пока ролик грузится, и остаётся, если видео
  не загрузилось, включён режим экономии трафика или «уменьшить движение».
- Если мобильного ролика нет, телефон покажет компьютерный (обрежется по краям).
- Звука нет вообще: браузеры не разрешают автоплей со звуком, а файл без дорожки легче.

**Как это работает на сайте**

- Ролик идёт сам, без звука, по кругу — только когда слайд на экране; при переходе
  на другой слайд он встаёт на паузу.
- Пока показан слайд с видео, карусель не листается автоматически: 6 секунд ждут
  ролик. Стрелки, точки и свайп работают как обычно.
- На телефоне уходит вертикальный файл, на компьютере — широкий.
- Слайд с видео выше обычного: **600 px** на компьютере и **480 px** на телефоне.

**Требования к ролику**

- MP4 (H.264), 24–25 кадров/с, длительность 6–8 секунд, без звука, `+faststart`.
- Бесшовный цикл: первый кадр = последний, иначе виден «прыжок».
- Не вписывайте текст в видео — весь текст задаётся полями баннера.
- Важное держите в правой части кадра: слева стоит белая плашка с заголовком и кнопкой.
- Спокойный план (облака, вода, лёгкая панорама) весит меньше, чем быстрая камера и рябь.

**Пережать под размер** (если умеете FFmpeg):

```
ffmpeg -i hero-src.mp4 -an -vf "scale=1280:640:flags=lanczos" -c:v libx264 -profile:v high ^
  -pix_fmt yuv420p -r 25 -crf 23 -maxrate 2M -bufsize 4M -g 50 -keyint_min 50 -sc_threshold 0 ^
  -movflags +faststart hero-desktop.mp4

ffmpeg -i hero-mob-src.mp4 -an -vf "scale=720:900:flags=lanczos" -c:v libx264 -profile:v high ^
  -pix_fmt yuv420p -r 25 -crf 25 -maxrate 850k -bufsize 1.7M -g 50 -movflags +faststart hero-mobile.mp4
```

**Если видео не показывается**

- Видна только картинка → проверьте, что поле «Видео…» заполнено и баннер опубликован.
- На iPhone в режиме экономии энергии автоплей запрещён системой — останется постер, это нормально.
- Проверить вес: правый клик по файлу → «Свойства». Больше 2 МБ (ПК) / 1 МБ (моб.) — пережмите.

## Если что-то пошло не так

- Баннер не видно на главной → проверьте: «Зона» = «Слайдер главной (hero)»,
  статус «Опубликован», «Показывать до» не в прошлом, картинка заполнена.
- Картинка «размытая» → загрузите файл нужного размера (1920 × 740 для компьютера).
- Ничего не помогает → напишите разработчику, приложите название баннера.
